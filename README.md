# arta-assets

Official logos, icons and brand assets for the Arta Blockchain ecosystem and its tokens.

## Contents

| File | Description |
|---|---|
| `logo_1024x1024.png` | Primary Arta Blockchain logo |
| `T_logo_512x512.png` / `T_logo_2048x2048.png` | Token logo (various resolutions) |
| `TINERTIA_clean_32x32.png` | TINERTIA favicon/small icon |
| `USDCa_logo_512.jpg` | USDC.a token logo |

## Usage

These assets are provided for use in wallets, explorers, exchanges, and third-party
integrations that list Arta ecosystem tokens (TINERTIA, USDT.a, USDC.a).

For token contract addresses and metadata, see [arta-core](https://github.com/artablok/arta-core).
